# Публичные примеры для страницы предложения

- `portfolio/` — исходный статический дизайн «Форма» из `artifacts/1/public`, без API и подключения к рабочей админке.
- `tools/` — демонстрационный магазин «ТОЛК»: поиск, категории, сортировка, карточки товаров, корзина и демонстрация оформления без отправки заказов.
- В обоих каталогах `admin.html`, `demo-admin.js`, `demo-admin.css` показывают интерфейс управления. Изменения не отправляются на сервер, не сохраняются в хранилище браузера и не меняют публичный сайт. Выбранные изображения показываются через временный Blob URL только на открытой странице.

Исходные формулировки и опубликованные адреса: `src/data/site-examples.json`.
Превью для карточек страницы предложения: `public/examples/`.
Для локального просмотра: `python3 -m http.server 4322 --directory artifacts/examples`, затем `/portfolio/index.html` или `/tools/index.html`.

Публиковать только содержимое двух каталогов в новый префикс существующего демо-бакета. README, ключи окружения и материалы рабочей админки не загружать.

Магазин использует локальные фотографии реальных инструментов из `tools/images/`.
Авторы, лицензии и ссылки на оригиналы: `tools/photo-credits.html`; этот файл и
каталог изображений публикуются вместе с магазином.
