# Автономный сайт с админкой для PHP/MySQL-хостинга

Пакет подходит для SpaceWeb, HostiMan, Hostinger и другого виртуального
хостинга с PHP 8.1+, PDO MySQL, HTTPS и отдельной пустой базой MySQL.
Node.js, Convex, VPS, Composer и SSH не нужны.

Откройте PDF-инструкцию именно для своего хостинга. После загрузки файлов и
создания базы установка выполняется по адресу:

`https://ВАШ-ДОМЕН/install.php`

Введите реквизиты базы и ключ из `INSTALL-KEY.txt`. После успешной установки
страница установки, серверная копия ключа и временный экспорт удалятся сами.
Админка находится по адресу `https://ВАШ-ДОМЕН/admin.html`.

Папка `private` должна лежать рядом с веб-корнем, а не внутри него. Не
публикуйте персональный ZIP и не устанавливайте права 777.
