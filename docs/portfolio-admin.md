# Админка портфолио 03212396

Статический сайт: `demo-sites/portfolio-03212396/`. Данные и файлы — отдельные
таблицы `portfolios`, `portfolioAssets` и файловое хранилище существующего Convex.
Изменение портфолио не меняет заявки и их права доступа.

Вход: `admin.html` в том же каталоге, что и демо. Секретный ключ хранится только
у владельца, не включается в URL, JavaScript или git. На сервере проверяется SHA-256
из переменной `PORTFOLIO_03212396_ADMIN_HASH` до первой смены ключа; после смены
актуальный хеш находится в закрытой таблице `portfolioAccess`.
При входе ключ обменивается на подписанный токен сроком на 15 минут и больше
не используется для запросов. Токен живёт только в памяти страницы. Передавайте
ключ клиенту отдельным приватным сообщением.
Это одноадминистраторский доступ к одной демке, не многопользовательская система.

## Сессии, отзыв и история

- Сессия действует 15 минут от входа, без продления активностью. Истечение
  проверяется сервером, в том числе непосредственно при записи/завершении загрузки.
  Несохранённые поля остаются в открытой вкладке при повторном входе, но не после перезагрузки.
- «Выйти» и «Завершить все сессии» отзывают все токены этого портфолио.
  Сам ключ при этом действует: для окончательного отзыва доступа смените ключ.
- «Подготовить новый ключ» → скачайте/сохраните его → «Применить новый ключ».
  Старый ключ и все токены прекращают работать. Ключ не меняется до применения.
  При потере ответа сети попробуйте войти новым сохранённым ключом.
- История закрыта авторизацией, показывает 50 последних событий: входы,
  отзыв доступа и публикации. Каждая новая публикация сохраняется со снимком.
  Версию можно загрузить в форму, затем опубликовать как новую; история не стирается.
  Состояние, существовавшее до включения истории, сохраняется перед его первой заменой.
  Более ранние изменения восстановить задним числом невозможно. История — не отдельный backup.

Подпись токенов: `PORTFOLIO_SESSION_SECRET` (отдельный секрет Convex).
Его замена немедленно делает все ранее выданные токены недействительными.
Аварийное восстановление ключа после его смены требует доступа разработчика к Convex:
изменить `portfolioAccess.keyHash` и увеличить `epoch`; одной смены исходной env-переменной недостаточно.

Лимиты через `@convex-dev/rate-limiter`, общие для этого портфолио, не по IP:
вход — 5 запросов/мин, загрузки — 10/мин, прочие авторизованные операции — 60/мин,
публичное чтение — 120/мин, ответ на неверную сессию — 30/мин. Используется token bucket
с начальным запасом в размере минутного лимита; ответ HTTP 429 содержит Retry-After.
При атаке общий лимит может временно ограничить и владельца. Это ограничение
на уровне приложения, не защита от DDoS и не гарантия нулевых расходов на входящие запросы.

Все функции работают в существующем Convex: отдельная VM, API-служба, Redis или
новая БД не нужны. Размещение админки на общем origin с демо остаётся риском;
короткие сессии не заменяют будущий перенос на отдельный доверенный домен.

Сначала войдите, заполните данные автора, добавьте работы и загрузите изображения.
PDF журнала необязателен. Нажмите «Опубликовать изменения»: это заменит демонстрационные
примеры реальными работами, в том числе для посетителей на других устройствах.
При конфликте двух вкладок сохранение отклоняется; скопируйте несохранённый текст
и перезагрузите страницу. Публикуйте только материалы, предназначенные для открытого доступа.

Лимиты: 40 работ, 8 МБ на файл, 100 файлов и 100 МБ на портфолио.
Поддерживаются JPG, PNG, WebP, PDF; SVG/HTML/JS не принимаются. Проверяются тип и
сигнатура файла (это не антивирусная проверка). Удаление работы убирает её из портфолио,
но не удаляет сам загруженный файл: он учитывается в квоте, а прямая ссылка может
оставаться доступной. Для физической очистки файлов обратитесь к разработчику.

Backend выкладывается обычным workflow проекта. После него статические файлы:

```sh
node --env-file=.env.automation.production scripts/publish-portfolio.mjs
```

Проверки Convex: все новые функции внутренние; запись доступна только через
HTTP-обработчик с ключом; загрузки и сохранение ограничены по размеру;
файлы чужих заявок нельзя привязать к портфолио. Старые заявки не мигрируются.
