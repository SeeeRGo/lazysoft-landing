# Админка портфолио 03212396

Статический сайт: `demo-sites/portfolio-03212396/`. Данные и файлы — отдельные
таблицы `portfolios`, `portfolioAssets` и файловое хранилище существующего Convex.
Изменение портфолио не меняет заявки и их права доступа.

Вход: `admin.html` в том же каталоге, что и демо. Секретный ключ хранится только
у владельца, не включается в URL, JavaScript или git. На сервере проверяется SHA-256
из переменной `PORTFOLIO_03212396_ADMIN_HASH`. В браузере ключ живёт только в памяти
до выхода или перезагрузки. Передавайте ключ клиенту отдельным приватным сообщением.
Это одноадминистраторский доступ к одной демке, не многопользовательская система.

Сначала войдите, заполните данные автора, добавьте работы и загрузите изображения.
PDF журнала необязателен. Нажмите «Опубликовать изменения»: это заменит демонстрационные
примеры реальными работами, в том числе для посетителей на других устройствах.
При конфликте двух вкладок сохранение отклоняется; скопируйте несохранённый текст
и перезагрузите страницу. Публикуйте только материалы, предназначенные для открытого доступа.

Лимиты: 40 работ, 8 МБ на файл, 100 файлов и 100 МБ на портфолио.
Поддерживаются JPG, PNG, WebP, PDF; SVG/HTML/JS не принимаются. Проверяются тип и
сигнатура файла (это не антивирусная проверка). Удаление работы убирает её из портфолио,
но не удаляет сам загруженный файл: он учитывается в квоте, а прямая ссылка может
оставаться доступной. Для физической очистки файлов обратитесь к разработчику.

Backend выкладывается обычным workflow проекта. После него статические файлы:

```sh
node --env-file=.env.automation.production scripts/publish-portfolio.mjs
```

Проверки Convex: все новые функции внутренние; запись доступна только через
HTTP-обработчик с ключом; загрузки и сохранение ограничены по размеру;
файлы чужих заявок нельзя привязать к портфолио. Старые заявки не мигрируются.
