Cloudflare Workers + D1 + R2

Как запустить сайт и админку в Cloudflare

Один установочный архив, автоматический HTTPS и бесплатный технический адрес. База, изображения и серверная часть создаются мастером установки.

Ваш сайт и его админка

Пример адреса: ИМЯ-САЙТА.АККАУНТ.workers.dev
Админка: тот же адрес + /admin.html

Это схема адреса. Установщик покажет вашу готовую ссылку — скопируйте её целиком. Название зависит от вашего проекта и аккаунта.

Сертификат выпускать не нужно. Адрес workers.dev сразу работает по HTTPS. Позже можно подключить собственный домен.

Перед началом

Что понадобится

У владельца

  • обычный компьютер;
  • электронная почта;
  • аккаунт Cloudflare;
  • 10–20 минут;
  • персональный ZIP от разработчика.

Создаст мастер

  • Worker и страницы;
  • базу D1;
  • закрытое хранилище R2;
  • первоначальное содержимое;
  • адрес с HTTPS.
Ориентир по бесплатным лимитам: 100 000 Worker-запросов в сутки, 5 ГБ D1 и бесплатная квота R2 10 ГБ-месяцев. Расход зависит от посещаемости, объёма файлов и функций сайта. Проверяйте Usage в панели.
R2 может попросить отдельно активировать хранилище или добавить платёжные данные. Это не включает платный Workers-план. Следите, чтобы в аккаунте оставался тариф Workers Free.
Архив персональный. В нём находится ключ админки. Не отправляйте ZIP в общий чат и не публикуйте в облаке открытой ссылкой.
Подготовка2

Шаг 1

Создайте аккаунт Cloudflare

  1. Откройте https://dash.cloudflare.com/sign-up.
  2. Укажите почту и придумайте отдельный сильный пароль.
  3. Подтвердите почту, если придёт письмо.
  4. Войдите в панель Cloudflare.
  5. Пока не создавайте Worker, D1 или R2 вручную.
https://dash.cloudflare.com/
Если R2 ещё не активирован: откройте в левой части панели R2 Object Storage и выполните предложенную активацию. После этого вернитесь к инструкции.
Никому не передавайте пароль Cloudflare. Мастер использует официальный вход через браузер и не просит вводить пароль в чёрном окне.
Аккаунт3

Шаг 2

Установите Node.js LTS

Это программа, которая один раз запустит мастер Cloudflare. Сам сайт после установки не зависит от вашего компьютера.

  1. Откройте https://nodejs.org/.
  2. Скачайте версию с пометкой LTS.
  3. Запустите установщик.
  4. На всех шагах оставьте обычные настройки и нажимайте Next.
  5. После завершения перезагрузите компьютер, если установщик попросит.
Node.js нужен только для первой публикации и будущих обновлений исходников. Держать программу постоянно запущенной не требуется.
Скачивайте Node.js только с официального сайта. Не устанавливайте «ускорители», расширения браузера или сторонние сертификаты.
Node.js4

Шаг 3

Распакуйте персональный архив

  1. Скачайте полученный от разработчика ZIP-архив сайта для Cloudflare. Имя файла может быть любым.
  2. Создайте папку, например «Мой сайт» внутри папки «Документы».
  3. Нажмите ZIP правой кнопкой и выберите «Извлечь всё».
  4. Откройте полученную папку.

Названия страниц и разделов зависят от вашего сайта. Для установки найдите перечисленные ниже служебные файлы.

📁 Мой сайт
├── ▶ install-cloudflare.cmd
├── 🔑 INSTALL-KEY.txt
├── 📘 ИНСТРУКЦИЯ-CLOUDFLARE.pdf
├── 📁 public
├── 📁 src
└── ⚙ остальные служебные файлы
Не запускайте мастер прямо внутри ZIP. Сначала обязательно извлеките все файлы в обычную папку.
Файл INSTALL-KEY.txt — ключ от админки. Сохраните его в менеджере паролей после проверки сайта.
Архив5

Шаг 4

Запустите мастер

Windows

  1. Дважды нажмите install-cloudflare.cmd.
  2. Откроется чёрное окно. Не закрывайте его.
  3. Когда откроется браузер Cloudflare, войдите в нужный аккаунт.
  4. Нажмите Allow / Разрешить.
  5. Вернитесь в чёрное окно и дождитесь слова ГОТОВО.

macOS или Linux

Откройте Терминал в распакованной папке и выполните:

sh install-cloudflare.sh
Первый запуск скачивает официальный инструмент Wrangler, поэтому антивирус или брандмауэр может спросить разрешение на доступ в интернет.
Если появится ошибка R2, активируйте R2 Object Storage в панели Cloudflare и снова запустите тот же файл. Мастер продолжит с сохранённого шага.

Шаг 5

Откройте сайт и админку

В конце мастер напечатает ваш адрес, заканчивающийся на workers.dev. Скопируйте его целиком. Ниже только схема адреса, а не готовая ссылка.

https://ИМЯ-САЙТА.АККАУНТ.workers.dev/

Для входа в управление добавьте:

https://ИМЯ-САЙТА.АККАУНТ.workers.dev/admin.html
  1. Откройте INSTALL-KEY.txt.
  2. Скопируйте единственную строку без пробелов.
  3. Вставьте её в поле входа.
  4. Измените один текст, опубликуйте и обновите главную страницу.
  5. Загрузите небольшое тестовое изображение.
Если текст и изображение появились, Worker, D1 и R2 связаны правильно.

Безопасность и обновления

Что сделать после запуска

  • в админке создайте новый ключ и сохраните его;
  • скачайте резервную копию после заполнения;
  • храните копию и ключ вне папки сайта;
  • не отправляйте содержимое окна установки посторонним;
  • при потере устройства нажмите «Отозвать все сессии»;
  • для обновления исходников снова запустите мастер.
Сессия админки действует 15 минут. Есть ограничение попыток входа, отзыв доступа и история публикаций.
Удаление локальной папки не удаляет сайт. Но без неё сложнее обновлять Worker. Сделайте закрытую копию всей папки после успешной установки.
Не удаляйте D1 и R2 в панели Cloudflare: в D1 находятся тексты и история, в R2 — загруженные изображения и PDF.

Неисправности

Если что-то не получилось

Команда node не найденаУстановите Node.js LTS, затем перезагрузите компьютер.
Ошибка входа CloudflareСнова запустите мастер и разрешите доступ в открывшемся браузере.
Ошибка R2 / bucketОткройте R2 Object Storage в панели, активируйте сервис и повторите запуск.
Адрес workers.dev не открываетсяПодождите 1–2 минуты, обновите страницу без кэша и проверьте, что скопирован весь адрес.
Неверный ключ админкиИспользуйте строку из INSTALL-KEY.txt именно от этого архива.
Мастер прервалсяНичего не удаляйте. Запустите его ещё раз: выполненные этапы отмечены в installation-state.json.
Для помощи отправьте снимок ошибки, но закройте на нём ключ, почту и идентификаторы аккаунта.

Собственный домен

Подключите позже без сертификатов

  1. Добавьте домен в аккаунт Cloudflare и дождитесь его активации.
  2. Откройте Workers & Pages.
  3. Выберите Worker вашего сайта. Его имя указано в адресе перед первой точкой.
  4. Откройте Settings → Domains & Routes.
  5. Нажмите Add → Custom Domain.
  6. Введите домен или поддомен и подтвердите.
Cloudflare сам создаёт нужную DNS-запись и выпускает HTTPS-сертификат для Custom Domain. Загружать .crt и .key не нужно.
Сначала убедитесь, что домен уже активен в этом же аккаунте Cloudflare. Адрес workers.dev можно оставить как резервный.
