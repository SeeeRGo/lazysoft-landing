Перед началом

Что означает «бесплатно»

Оплата не нужна

  • технический адрес workers.dev;
  • автоматический HTTPS;
  • Worker для сайта и API;
  • D1 для текстов и истории;
  • KV для изображений и PDF.

Но есть лимиты

  • 100 000 Worker-запросов в день;
  • 10 мс CPU на вызов;
  • D1: 5 ГБ всего;
  • KV: 1 ГБ на аккаунт;
  • KV: 1000 записей в сутки.
Размер сайта сам по себе не определяет расход квот. Это оценка, а не гарантия: проверяйте Usage в панели Cloudflare.
Не подключайте Workers Paid. Этот комплект использует KV и не требует подключения R2 или карты. На Free превышение квот приводит к ошибкам. Если открыт экран оплаты R2, закройте его и используйте обновлённый установщик.
Актуальные официальные лимиты приведены на странице 12. Cloudflare может менять условия.

Схема

Из чего состоит сайт

1. Workers Static Assets

Отдаёт посетителю страницы, стили и скрипты.

2. Worker API

Проверяет ключ, создаёт короткие сессии, ограничивает запросы и связывает админку с данными.

3. D1

Тексты, настройки, история изменений и отозванные сессии.

4. Workers KV

Загруженные изображения и PDF. Новые файлы могут распространяться около минуты или дольше.

Удаление любого из трёх ресурсов ломает часть сайта. После установки не удаляйте Worker, D1 или KV из панели.
Компьютер владельца после публикации может быть выключен: сайт работает в Cloudflare.
Архитектура3

Шаг 1

Подготовьте аккаунт и компьютер

  1. Создайте аккаунт: https://dash.cloudflare.com/sign-up.
  2. Подтвердите почту и войдите в панель.
  3. Установите Node.js с пометкой LTS: https://nodejs.org/.
  4. Скачайте полученный ZIP-архив сайта для Cloudflare. Название файла может отличаться.
  5. Распакуйте ZIP в отдельную обычную папку.

Названия страниц и разделов зависят от вашего сайта. Для установки найдите перечисленные ниже служебные файлы.

📁 Мой сайт
├── ▶ install-cloudflare.cmd
├── ▶ install-cloudflare.sh
├── 🔑 INSTALL-KEY.txt
├── 📘 ИНСТРУКЦИЯ-CLOUDFLARE.pdf
├── 📁 public
├── 📁 src
└── ⚙ служебные файлы
Не запускайте файлы внутри ZIP. INSTALL-KEY.txt — секретный ключ админки. Не отправляйте архив публичной ссылкой.
Подготовка4

Шаг 2

Откройте Терминал в папке

Windows

  1. Откройте распакованную папку в Проводнике.
  2. Нажмите строку с адресом папки.
  3. Введите cmd и нажмите Enter.

macOS

  1. Откройте папку в Finder.
  2. Правой кнопкой по папке → Службы → Новый терминал в папке.

Linux

Правой кнопкой в пустом месте папки → Открыть в терминале.

Проверьте Node.js:

node --version
Должен появиться номер версии, например v22… или новее.
Если написано «команда не найдена», закройте Терминал, установите Node.js LTS и откройте его заново.
Терминал5

Шаг 3

Войдите в Cloudflare через браузер

Окно Терминала должно оставаться открытым до завершения входа.

npm install
npx wrangler login --device
  1. Браузер откроет официальный сайт Cloudflare.
  2. Проверьте адрес dash.cloudflare.com.
  3. Войдите в нужный аккаунт, сверьте код с Терминалом и нажмите Allow / Разрешить.
  4. Дождитесь сообщения об успешной авторизации.
  5. Вернитесь в Терминал и выполните:
npx wrangler whoami
Если показаны ваша почта и Account ID, вход выполнен.
Не вставляйте пароль Cloudflare, API-токен или INSTALL-KEY.txt в чужие сайты и сообщения.
Авторизация Wrangler6

Если callback не открылся

Ошибка localhost:8976

Страница ERR_CONNECTION_REFUSED означает, что браузер не смог подключиться к локальному приёмнику Wrangler. Вход по коду ниже не требует localhost.

  1. Закройте старую вкладку с ошибкой.
  2. В Терминале снова выполните:
npx wrangler login --device
  1. Не закрывайте Терминал.
  2. Авторизуйтесь только в новой вкладке, которая открылась после команды.
  3. Сверьте код с Терминалом и нажмите Allow до истечения указанного срока.
  4. Проверьте вход командой npx wrangler whoami.
После таймаута старую вкладку localhost можно закрыть. Используйте новую ссылку и код из Терминала.
Если браузер не открылся, скопируйте свежую ссылку из Терминала вручную. Команда должна продолжать работать, пока вы подтверждаете вход.

Шаг 4

Запустите установщик

Windows

Дважды нажмите install-cloudflare.cmd или выполните в уже открытом окне:

install-cloudflare.cmd

macOS / Linux

sh install-cloudflare.sh

Установщик автоматически:

  • создаст отдельную D1-базу;
  • создаст хранилище Workers KV;
  • загрузит исходные изображения;
  • создаст Worker и привяжет ресурсы;
  • наполнит базу исходным содержимым;
  • напечатает адрес сайта и админки.
Первый запуск может занять несколько минут. Не закрывайте окно, пока не появится ГОТОВО.

Если установщик остановился

Безопасное повторение

Cloudflare просит карту для R2R2 больше не нужен. Закройте этот экран и запустите обновлённый комплект Workers + D1 + KV.
Authentication requiredВыполните npx wrangler login --device, проверьте whoami, затем повторите запуск.
Команда npm или npx не найденаПереустановите Node.js LTS и заново откройте Терминал.
Интернет прервалсяПодключитесь снова и повторно запустите тот же файл.
Прерванная установкаСохраните installation-state.json и повторите запуск. Созданные ресурсы будут найдены, загрузка файлов продолжится.
При смене аккаунта установщик сохраняет старый прогресс отдельно. Новая установка получает данные из архива. Тексты и файлы из другого аккаунта автоматически не переносятся.

Шаг 5

Проверьте сайт и админку

Скопируйте полный адрес, который показал установщик. Ниже только схема — слова ИМЯ-САЙТА и АККАУНТ не нужно вводить буквально:

https://ИМЯ-САЙТА.АККАУНТ.workers.dev/

Админка находится здесь:

https://ИМЯ-САЙТА.АККАУНТ.workers.dev/admin.html
  1. Откройте INSTALL-KEY.txt.
  2. Вставьте ключ в форму входа.
  3. Измените один короткий текст и опубликуйте.
  4. Обновите главную страницу в другом окне.
  5. Загрузите небольшое изображение и снова проверьте сайт.
Если тексты и изображения появились, Worker, D1 и KV работают вместе. Новый файл может появиться через минуту или позже: подождите и обновите страницу.
Не вводите ключ админки, если браузер показывает предупреждение о сертификате. Для workers.dev нормальный адрес всегда начинается с https://.
Приёмка10

Эксплуатация

Ключи, копии и обновления

  • сразу замените первоначальный ключ в админке;
  • сохраните новый ключ в менеджере паролей;
  • скачайте резервную копию после заполнения;
  • храните ZIP и копию в закрытом месте;
  • при потере устройства отзовите все сессии;
  • для обновления кода снова запустите установщик.
Админ-сессия короткая. В проекте есть ограничение попыток, отзыв сессий и история изменений.
Удаление папки на компьютере не удаляет опубликованный сайт, но лишает вас простого способа обновления. Сохраните папку целиком.
Полная копия включает тексты, файлы и историю: до 40 файлов и 32 МБ суммарно. При превышении сохраняйте файлы отдельно. Если файл ещё распространяется, повторите создание копии позже.

Необязательно

Собственный домен позже

  1. Купите домен у любого регистратора.
  2. Добавьте его в тот же аккаунт Cloudflare.
  3. Дождитесь статуса Active.
  4. Откройте Workers & Pages → ваш Worker.
  5. Выберите Settings → Domains & Routes → Add → Custom Domain.
  6. Введите домен и подтвердите.
Cloudflare создаёт маршрут и выпускает HTTPS-сертификат. Файлы .crt и .key загружать не требуется.
Покупка домена уже не относится к полностью бесплатному варианту. Технический workers.dev можно оставить как резервный адрес.
