Шаг 1

Выберите правильную услугу

  1. Откройте https://www.hostinger.com/web-hosting.
  2. Выберите обычный Web Hosting с поддержкой PHP/MySQL.
  3. Проверьте полный платёж сейчас и стоимость продления.
  4. Сохраните условия возврата и подтверждение заказа.
  5. Войдите в hPanel.
https://www.hostinger.com/web-hosting
Не выбирайте Hostinger Website Builder: его файловый менеджер недоступен, а передаваемый сайт нельзя загрузить как обычный PHP-проект.
Возврат — не бесплатный тариф. Домены и отдельные услуги могут иметь другие правила возврата; перед оплатой прочитайте текущую политику.

Шаг 2

Создайте пустой сайт

  1. Откройте раздел Websites.
  2. Нажмите Add website.
  3. Выберите Empty website, а не WordPress/Builder.
  4. Выберите автоматически созданный временный домен либо свой домен.
  5. Откройте Dashboard созданного сайта.

Шаг 3

Проверьте автоматический SSL

Hostinger устанавливает бесплатный Lifetime SSL автоматически при добавлении сайта или поддомена. Это может занять 1–2 часа.

  1. Откройте Websites → Dashboard → SSL.
  2. Убедитесь, что статус сертификата активен.
  3. Откройте сайт по https:// без предупреждения.
  4. Если статус Failed держится больше двух часов, откройте меню ⋮ и выберите Reinstall.
https://ВАШ-ВРЕМЕННЫЙ-ДОМЕН/
Не запускайте install.php по HTTP. Если используете свой домен, сначала направьте его на Hostinger и дождитесь DNS и SSL.
После установки SSL Hostinger по умолчанию принудительно включает HTTPS.

Шаг 4

Создайте пустую MySQL-базу

  1. Откройте Websites → Dashboard.
  2. В боковом меню найдите Databases → Management.
  3. В блоке создания введите имя базы, пользователя и пароль.
  4. Нажмите Create.
  5. Скопируйте полные имена с префиксом вида u123456789_.

Шаги 5–6

Распакуйте ZIP уровнем выше

  1. Откройте Dashboard → File Manager.
  2. Выберите Access all files of web hosting, не «files of domain».
  3. Откройте domains → ваш-домен: здесь видна public_html.
  4. Загрузите portfolio-php-mysql.zip.
  5. Нажмите правой кнопкой по ZIP → Extract в текущую папку.

Не распаковывайте ZIP внутри public_html. Папка private должна быть рядом с ней, чтобы пароли базы не были доступны посетителям.

Шаг 8

Войдите в админку

https://ВАШ-ДОМЕН/admin.html
  1. Введите ключ из INSTALL-KEY.txt.
  2. Подготовьте новый ключ в админке и сохраните его.
  3. Измените контент и проверьте обычный сайт.
  4. Скачайте первую резервную копию JSON.
  5. Удалите ZIP с хостинга.
Сессия истекает через 15 минут бездействия. Можно отозвать все сессии; публикации записываются в историю.
