# Автономная передача портфолио 03212396

Состояние на 08.09.2026: создан отдельный комплект `standalone/portfolio`, адаптированный под Node.js/Passenger на виртуальном хостинге Beget; Docker/VPS — резервный вариант. По последующему запросу опубликовано автономное демо на отдельной VM Яндекс Облака: [адрес и инфраструктура](portfolio-demo-production.md). Инструкция установки, ограничения и сравнение хостингов: [README комплекта](../standalone/portfolio/README.md).

Опубликованный сайт на Yandex Object Storage и его Convex backend **не переключены и не удалены**. Другие заявки/сайты Lazysoft продолжают использовать Convex. Эта работа не удаляет Convex из основного проекта.

## Экспорт и упаковка для оператора

Из корня этого репозитория, с уже настроенным доступом Convex CLI:

```sh
node scripts/export-portfolio-standalone.mjs
```

Скрипт выполняет только read-only inline query, только по slug `03212396`, копирует текущую версию, все зарегистрированные файлы и историю в новый каталог `.local/portable-portfolio-*/data`. Не читает таблицы заявок, ключи или сессии. Проверяет размер/сигнатуры файлов и неизменность снимка до/после скачивания. При превышении ограничений останавливается вместо обрезания данных.

По выведенному **точному** пути, не по glob:

```sh
node scripts/package-portfolio-standalone.mjs /absolute/export-directory/data
```

Получится приватный `.local/portfolio-handover-*/portfolio.tar.gz`. Упаковщик использует allowlist файлов, SQLite Backup API, удаляет ключ/сессии/лимиты **только в копии**, затем делает VACUUM. `.env`, ключи облака, операторские скрипты и старый ключ админки в архив не входят. Пользовательский контент не коммитится в Git.

Новый владелец создаёт свой ключ при установке. Контент и история в архиве соответствуют времени экспорта, не обновляются автоматически вслед за старой админкой. Перед окончательным переездом нужно на время прекратить правки старой версии и повторить экспорт.

## Проведённые проверки

- Экспорт: версия 1, одна опубликованная работа, три файла (458 073 байта), семь событий истории. Продакшен не изменялся.
- Семь изолированных Node-тестов: публикация/конфликт версий, загрузки и ограничения, история, короткие сессии, отзыв/ротация, сохранность после рестарта, резервная копия, закрытые пути, отсутствие облачных зависимостей и запуск через ссылку на релиз.
- Локальный preflight: Node 24.12.0, SQLite WAL, запись на диск и восстановление контрольной копии.
- Браузер: главная, четыре категории и админка на 390/1366 px. Нет горизонтального переполнения, битых изображений, JS-исключений и сетевых запросов к старому backend.

На аккаунте Beget/Selectel проверок **ещё не было**. Совместимость конкретного сервера, Passenger и хранения должна быть подтверждена при установке. Платная VM для демо создана в Яндекс Облаке, где повторены серверные и браузерные проверки; это не проверка Beget.

## Следующий шаг

Для окончательной передачи клиенту выбрать аккаунт Beget с подходящим окружением либо VPS; проверить требования из README, повторить проверки доступа/перезапуска/восстановления и перенести на клиентский домен. Автономное демо уже доступно по новому адресу, старая версия остаётся отдельной копией для отката.
