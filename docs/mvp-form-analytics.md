# Аналитика заявки на разбор идеи

Форма на `/mvp-za-3-dnya/` отправляет технические события в Яндекс Метрику. Текст идеи и сам контакт в аналитику не передаются: они отправляются владельцу сайта через сервер только после успешной отправки формы.

## Основная воронка

| Событие | Что означает |
| --- | --- |
| `mvp_landing_view` | Открыта страница предложения |
| `mvp_brief_started` | Пользователь впервые начал заполнять форму |
| `mvp_brief_form_completed` | Сервер принял заявку и доставил её владельцу сайта |
| `mvp_request_submitted` | То же успешное действие с параметром выбранного канала |

Существующие цели `mvp_brief_started` и `mvp_brief_form_completed` сохранены, поэтому их не нужно пересоздавать в Метрике. Старые цели шагов формы, скачивания PDF и переходов к контакту больше не используются новой страницей.

## Диагностика

- `mvp_request_field_started` — начато заполнение `idea` или `contact`;
- `mvp_request_contact_method` — выбран `telegram`, `email` или `max`;
- `mvp_voice_input_used` — идея успешно продиктована;
- `mvp_request_validation_error` — идея или контакт не прошли проверку;
- `mvp_request_submit_failed` — сервер не смог доставить заявку.

В Директе основной целью должна быть `mvp_brief_form_completed`. Событие срабатывает только после ответа сервера об успешной доставке, а не просто после клика по кнопке.

## Доставка заявок

В GitHub Actions → Settings → Secrets and variables → Actions → Repository secrets должны быть добавлены:

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — идентификатор чата, куда бот присылает заявки;
- `CONVEX_DEPLOY_KEY` — ключ production deployment для публикации функций;
- `CONVEX_INGEST_SECRET` — секрет серверной записи заявок.

В Repository variables должна быть задана `CONVEX_SITE_URL` — адрес HTTP Actions production deployment.

После настройки отправьте тестовую идею с UTM-метками и проверьте одновременно сообщение в Telegram и достижение цели `mvp_brief_form_completed`.

Каждая заявка также резервно записывается в таблицу `mvpRequests` в Convex. Публичных функций чтения у таблицы нет; данные доступны владельцу проекта через Convex Dashboard. Заявка считается принятой, если сработал хотя бы один из каналов — Convex или Telegram.
