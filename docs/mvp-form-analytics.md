# Аналитика формы ТЗ

Форма `/mvp-za-3-dnya/#brief` отправляет технические события в Яндекс Метрику. Тексты ответов, имя, имена файлов и содержимое скриншотов в аналитику не передаются.

## Основная воронка

| Событие | Что означает |
| --- | --- |
| `mvp_landing_view` | Открыта страница предложения |
| `mvp_brief_started` | Пользователь впервые взаимодействовал с полем |
| `mvp_brief_step_completed` | Шаг пройден без ошибок обязательных полей |
| `mvp_brief_form_completed` | Нажата кнопка сборки ТЗ |
| `mvp_brief_local_ready` | Локальный черновик показан в браузере |
| `mvp_brief_ai_ready` | Получен структурированный ИИ черновик |
| `mvp_brief_pdf_downloaded` | Скачан PDF |
| `mvp_contact_telegram` | Переход в Telegram |
| `mvp_contact_email` | Переход к письму |

## Диагностика полей

- `mvp_brief_field_started` — поле получило фокус или первый ввод;
- `mvp_brief_field_completed` — пользователь оставил в поле ответ;
- `mvp_brief_validation_error` — обязательное поле пустое или короче минимальной длины;
- `mvp_brief_abandoned` — пользователь начал форму, но закрыл страницу до сборки ТЗ;
- `mvp_voice_input_used` — успешно распознан голосовой ответ;
- `mvp_existing_brief_file_added` — документ прочитан в браузере;
- `mvp_screenshot_added` — выбран и обработан скриншот.

Для событий полей передаются только безопасные параметры:

- `field`: техническое имя поля (`idea`, `audience`, `problem` и так далее);
- `step`: номер шага;
- `method`: `text`, `voice`, `file` или `selection`;
- `startingPoint`: `idea` или `existing`;
- `duration`: интервал времени без точного значения.

## Где смотреть

События записываются двумя способами:

1. Как JavaScript-события `reachGoal`. Для основной воронки можно создать в счётчике Метрики JavaScript-цели с идентификаторами из таблицы выше.
2. Как параметры визита с первым уровнем `lazysoft_mvp`. Они позволяют сравнивать заполнение отдельных полей без создания отдельной цели на каждое поле.

Для поиска точек отсева сравнивайте `mvp_brief_field_started` и `mvp_brief_field_completed` по параметру `field`, затем проверяйте `mvp_brief_validation_error` и `mvp_brief_abandoned` по номеру шага.
