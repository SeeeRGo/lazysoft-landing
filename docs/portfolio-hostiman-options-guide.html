Что подготовить

Что понадобится для установки

  • ZIP-архив сайта для HostiMan от разработчика (имя файла может отличаться);
  • файл INSTALL-KEY.txt из архива;
  • доступ к почте для регистрации;
  • банковская карта для домена или Free+;
  • 20–40 минут спокойного времени.
📦 ZIP-архив вашего сайта
├── 📁 public_html  ← файлы, доступные посетителям
├── 📁 private  ← данные вне публичной папки
├── 🔑 INSTALL-KEY.txt
└── 📘 инструкция
Не публикуйте архив и INSTALL-KEY.txt. Ключ открывает админку. После установки замените его и сохраните новый в менеджере паролей.
Сайт использует PHP и MySQL. Node.js, VPS и SSH для установки не нужны.

Регистрация4

Вариант А · с доменом .ru

Купите домен и активируйте Free

  1. Войдите в личный кабинет HostiMan.
  2. В личном кабинете откройте Домены → Регистрация домена.
  3. Введите желаемое имя в зоне .ru и нажмите Проверить.
  4. Если имя свободно, выберите Использовать DNS HostiMan.
  5. Заполните данные владельца и оплатите регистрацию.
  6. Откройте страницу хостинга и закажите тариф Free.
По официальной странице HostiMan регистрация .ru активирует Free автоматически без верификации.
DNS и выпуск SSL могут занять время. HostiMan предупреждает, что домен после регистрации может начать работать в течение 24 часов.

Шаг 2 · снова общий путь

Найдите адрес и включите HTTPS

  1. Откройте карточку активированной услуги.
  2. Перейдите в панель управления хостингом.
  3. Найдите раздел WWW-домены или Домены.
  4. Запишите адрес: свой .ru либо выданный технический.
  5. Откройте раздел SSL и выберите бесплатный Let’s Encrypt.
  6. После выпуска откройте адрес с https://.
https://ВАШ-ДОМЕН/
Продолжайте только после появления замка без предупреждений.
Если технический домен не предлагается в списке SSL, создайте тикет в поддержку HostiMan. В тарифе Free+ бесплатный SSL заявлен официально.
Не открывайте install.php и админку через обычный http://: ключи нельзя передавать без шифрования.

Шаг 4

Загрузите и распакуйте архив

  1. Откройте Менеджер файлов.
  2. Найдите папку, внутри которой лежит корень вашего домена.
  3. Загрузите полученный ZIP-архив сайта для HostiMan.
  4. Выделите архив и выберите Извлечь.
📁 www или корневая папка аккаунта
├── 📁 ВАШ-ДОМЕН  ← существующий корень сайта
├── 📁 public_html  ← появится из ZIP
├── 📁 private  ← должна остаться снаружи сайта
└── 🔑 INSTALL-KEY.txt
Папку private нельзя класть внутрь публичного домена. Она должна быть рядом с папкой сайта и не открываться из Интернета.
Название корневой папки может отличаться. Откройте настройки WWW-домена и ориентируйтесь на указанную там директорию.

Шаг 5

Переместите публичные файлы

  1. Откройте распакованную папку public_html.
  2. Включите показ скрытых файлов.
  3. Выберите всё, включая .htaccess и .user.ini.
  4. Переместите выбранное в корневую папку вашего домена.
  5. Удалите стандартную заглушку хостинга, если она мешает.
