## Резервные копии

`portfolio-backup.timer` ежедневно запускает `portfolio-backup.service`; время — 04:00 UTC с разбросом до 5 минут. SQLite Backup API делает согласованную копию в `/srv/portfolio/data/backups`; остаются последние 14 успешных копий. Чужие файлы ротация не удаляет.

Это копии **на том же диске**, а не защита от потери всей VM/диска. Первоначальные экспорт и архив находятся локально в `.local`; для дальнейшей эксплуатации нужно регулярно скачивать отдельную приватную копию либо настроить отдельное закрытое хранилище. Базы включают хеш ключа и сессии: не публиковать их на сайте или в публичном бакете.

После развёртывания отдельная копия скачана на этот компьютер: `.local/portfolio-demo-snapshot-4NHI0p/data/portfolio.sqlite`; SQLite quick_check пройден. Для повторного скачивания последней серверной копии: `node scripts/backup-portfolio-demo.mjs`. Автоматическая отправка копий за пределы VM пока не настроена.
