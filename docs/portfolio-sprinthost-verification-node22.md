# Проверка автономной Node.js 22-версии — 8 сентября 2026

Пакет: `standalone/portfolio`; упаковка: `scripts/package-portfolio-sprinthost-node.mjs`.

## Результат

- 11 из 11 интеграционных тестов успешно пройдены локально, в Node.js 22.5.0 и в актуальном Node.js 22.
- Финальный ZIP распакован отдельно; 8 из 8 тестов серверной части успешно пройдены непосредственно из его содержимого в изолированном контейнере Node.js 22 без сети.
- Проведён имитационный цикл установки распакованного ZIP: создан новый ключ, приватный `hosting.json`, launcher с `--experimental-sqlite`, Passenger `.htaccess`, HTTPS-перенаправление и `tmp/restart.txt`.
- Проверена сборка персонального ZIP без SSH: абсолютные пути сформированы из логина и домена, `.htaccess` попадает в каталог нужного сайта, в базе ровно один новый ключ и нет сессий. Ключ из архива успешно создаёт администраторскую сессию.
- Проверены публикация, сохранение контента, история, конфликт версий, 15-минутные сессии, отзыв сессий, ротация ключа, ограничения частоты, загрузка файлов, резервная копия и сохранность данных после перезапуска.
- Резервная копия из админки очищается от действующих сессий и лимитов; временный файл после скачивания удаляется.
- Клиентский архив не содержит настроенного ключа администратора, сессий, `.env`, Convex/Yandex Cloud конфигурации или удалённых JavaScript/CSS-зависимостей.
- PDF имеет 15 страниц A4, текстовый слой, оглавляемые разделы, не содержит JavaScript; переполнение всех страниц проверено автоматически, выбранные страницы просмотрены визуально.

## Совместимость Node.js 22

SQLite появился в Node.js 22.5.0 за экспериментальным флагом. Совместимость проверена именно с 22.5.0 и с актуальной веткой 22. Для Sprinthost установщик запускается командой `node22 ~/portfolio/setup.mjs`, затем сам перезапускает себя с `--experimental-sqlite`. Passenger использует созданный установщиком launcher с тем же флагом.

## Границы проверки

Это локальная проверка целевого клиентского архива, а не вход в чужой аккаунт Sprinthost. Реальные DNS, сертификат, доступность Node.js 22 и квоты конкретного аккаунта проверяются при размещении. Персональный ZIP предназначен для нового или заранее подготовленного сайта; инструкция запрещает подтверждать замену существующих файлов без разработчика.
