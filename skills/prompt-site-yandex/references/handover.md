# Передача клиентского сайта

Worker собирает отдельный архив выбранной версии с двумя вариантами установки:
`cloudflare/` (Worker + D1 + KV, без R2) и `hostiman/` (PHP 8.1+ + PDO MySQL).
Пакеты создаёт `standalone/site-cms/package.mjs` из проверенного сайта и общей
CMS-схемы. Это не прежние упаковщики конкретного портфолио.

В каждом пакете свой ключ администратора, серверное сохранение, проверка версии,
короткая сессия и выход. Ключи генерирует упаковщик, они не попадают в публичный
демо-бакет и не передаются модели. PHP private находится вне веб-корня.

Проверь установку на пустое хранилище, вход, добавление/удаление записи, загрузку
изображения, редактирование контента, просмотр другим посетителем, конфликт
одновременного сохранения и выход. Демо локально для браузера, production — сервер.
Каталог без фиксированного ограничения количества записей, но сохранение ограничено
размером 2 МБ, файл — 8 МиБ, приложение ограничивает объём загрузок 1 ГБ; дополнительно
действуют квоты хостинга. Не обещай неограниченное хранилище или вечную бесплатность.

При новой модели содержимого не переписывай безопасные серверные части моделью:
расширь общий модуль с проверками. Не называй обычный каталог готовым интернет-магазином
с оплатой и заказами, пока эти сценарии не подключены и не проверены.

Покупка на странице заявки — запрос владельцу, не автоматическое списание денег.
Готовая версия доступна до покупки, клиентские исходники выдаются по процедуре
подтверждения оплаты. Обычный статический служебный ZIP не является клиентским пакетом.
